# Expense Tracker

A command-line Python application to record, track, and manage daily expenses.

## Features
* **Add Expenses:** Record new expenses with unique IDs.
* **View & Search:** Browse all recorded expenses or search for specific entries.
* **Category & Monthly Summaries:** View spending breakdowns by category and monthly totals.
* **Expense Insights:** Quickly find your highest and lowest expenses.
* **Delete Entries:** Remove outdated or incorrect expense records.

## How to Run
1. Make sure Python is installed on your computer.
2. Download `pjt_expense.py`.
3. Open your terminal or command prompt and run:

```bash
python pjt_expense.py
